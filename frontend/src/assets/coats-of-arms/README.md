# Coats of arms of the Swiss cantons

Shown on the right of a Swiss license plate (`components/licenseplate/LicensePlate.tsx`).
File name = canton code as on the plate (`SG.svg`).

- **Source:** Wikimedia Commons, files `Wappen <Kanton> matt.svg`
  (e.g. https://commons.wikimedia.org/wiki/File:Wappen_St._Gallen_matt.svg)
- **License:** all 26 files are marked *Public domain* on Commons (checked 2026-10-04).
- Downloaded once and stored here, so the app needs no internet connection.
- Checked: no scripts or external references. They are only used as `<img src>`, which never
  runs scripts inside an SVG anyway.

Cantonal coats of arms are official emblems: use them only to identify the canton of a plate.
